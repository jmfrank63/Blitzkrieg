# ResourceEditor fixtures

(`tools/zig/resource_editor_fixtures.zig`).
Do not edit by hand -- re-run the step after changing the
generator and commit the updated files together.

subclass in `Sources/src/editor/*Frm.cpp` (via `szExtension`
plus `szComposerSaveName`). The art column names this
fixture's placeholder source art and its kind; the hash
columns are the first 28 bits of each file's SHA-256 so an
agent can diff a run against this table without rereading
the file bytes.

## Unit (msh) source art

`msh/project.msh` names `1.mod`, `2.mod`, `3.mod` and the textures `1.tga`,
`1w.tga`, `1a.tga`, `2.tga`, `2w.tga`, `2a.tga`; the exporter also looks for
`icon.tga` in the project folder. The three models are copied unchanged from
the shipped `Data/Units/Technics/German/Artillery/8_8_cm_FlaK18` (the unit
ships all three, so the install and transportable variants are real
models); none of the project's locator references match that unit's nodes,
which the exporter reports as warnings. The seven targas are generated by
this tool, 16 x 16 solid colour, each coloured by its own file name.

## Object (obt) source art

`obt/project.obt` names `1.tga`, `1s.tga`, `1w.tga`, `1ws.tga`, `1a.tga` and
`1as.tga` (sprite and shadow per season), generated by this tool as 16 x 16
32-bit targas: an opaque 8 x 8 square, coloured by file name, in a transparent
frame (shadows black at half alpha). Its own_data and desc hold a passability
grid with origin (2, 1), transparency tiles 1..7, two trans-lines, a zero point
and a sprite position; the project file is hand-edited, not regenerated.

## Fence (fnc) source art

`fnc/project.fnc` points its Fences directory at `fences\` and holds five segments:
`art-16x16` and `ne-left` (north-east, safe and destroyed left), `nw`, `sw` and
`se`, with segment indices 0..4, locked tiles, transparences and a sprite position
each. `fnc/fences/` holds `<item>.tga` and `<item>s.tga` for every one of them,
generated by this tool as 16 x 16 32-bit targas (an opaque 8 x 8 square coloured
by file name; shadows black at half alpha, shifted). The project file is
hand-edited, not regenerated. The top-level `art-16x16.tga` is the generic
picture every picture kind gets and is not used by the fence export.
