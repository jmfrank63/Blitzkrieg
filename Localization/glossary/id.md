# Glossary: Indonesian (Bahasa Indonesia)

Scope: terms of the main menu, the mission briefing, unit types and ranks, so that the overlays (S02 T04), the checker (S03) and the documents (S08) use one translation per term. The English column is the 2003 game's wording.

Review state: machine seed, needs native review. The menu terms are what the `id` overlay uses; nothing here has been checked by a native speaker.

Vocabulary decisions (S05 T01): Indonesian uses basic Latin only, so the overlay keeps to ASCII plus the cp1252 punctuation the English source already uses. The player is addressed as Anda. Stat labels use Amun. (Amunisi), Jgk. (Jangkauan), Kec. (Kecepatan), Krsk. (Kerusakan) and Pert. (Pertahanan) only where the English is itself short. Ranks follow the TNI style (prajurit, kopral, sersan, letnan, kapten, mayor, kolonel, jenderal; sersan satu/dua/kepala, letnan satu/dua); crew names keep the surname and map only the rank word, and German player ranks (Oberst, Hauptmann, General-major) stay as designations. Weapons: senapan mesin, SMG (submachine gun, for fit), peluncur roket, senapan antitank, penembak jitu. Other recurring terms: regu (squad), formasi, lapis baja (armor), bala bantuan (reinforcements), rekrut (hire), pihak (side), tingkatkan (upgrade), Sekutu (Allies), Musuh (enemy). Water cisterns are Tangki air and the credits line Sound Engineer is Teknisi Suara; both are term exceptions. Vehicle classes (S05 T02): tank (tank sedang, tank ringan, tank berat), mobil lapis baja (armoured car), howitser, mortir, meriam antitank, meriam antipesawat, truk, pesawat tempur (fighter), pesawat pengebom (bomber), kendaraan setengah-rantai (half-track); weapon designations, model and place names stay unchanged, and specification labels are translated (SPESIFIKASI, Kecepatan, Daya, Berat, Persenjataan). Country names: Jerman, Inggris, Amerika, Prancis, Finlandia, Italia, Polandia, Rusia; GB, USA and USSR stay.
