# Projetos de teste dos editores do Blitzkrieg

Esta pasta traz uma pasta de fixture para teste rápido por editor de recursos.

## Como usar

1. Abra `manifest.json` e escolha a pasta do editor.
2. Se a pasta tiver um arquivo de projeto copiado, abra-o diretamente no `editor.exe`.
3. Se a pasta for `external-project-reference`, use o caminho externo do GOG indicado no `README.md` dessa pasta.
4. Se a pasta for `runtime-reference`, nenhum arquivo de projeto do composer foi encontrado; use o XML de execução indicado como a referência de dados mais próxima ao testar a inicialização do editor, os caminhos de importação e a renderização.

## Política de cópia

Somente arquivos que já estão neste repositório são copiados para cá. Os arquivos da instalação comercial do GOG são referenciados apenas pelo caminho e não são duplicados.
