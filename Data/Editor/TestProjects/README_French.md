# Projets de test des éditeurs Blitzkrieg

Ce dossier fournit un dossier de fixture de test rapide par éditeur de ressources.

## Mode d'emploi

1. Ouvrez `manifest.json` et choisissez le dossier de l'éditeur.
2. Si le dossier contient un fichier de projet copié, ouvrez-le directement dans `editor.exe`.
3. Si le dossier est `external-project-reference`, utilisez le chemin GOG externe indiqué dans le `README.md` de ce dossier.
4. Si le dossier est `runtime-reference`, aucun fichier de projet composer n'a été trouvé ; utilisez le XML d'exécution indiqué comme référence de données la plus proche pour tester le démarrage de l'éditeur, les chemins d'import et le rendu.

## Politique de copie

Seuls les fichiers déjà présents dans ce dépôt sont copiés ici. Les fichiers de l'installation commerciale GOG sont référencés par leur chemin uniquement et ne sont pas dupliqués.
