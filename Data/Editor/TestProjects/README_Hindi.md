# Blitzkrieg एडिटर परीक्षण प्रोजेक्ट

यह फ़ोल्डर हर रिसोर्स एडिटर के लिए स्मोक परीक्षण का एक फ़िक्स्चर फ़ोल्डर देता है।

## उपयोग कैसे करें

1. `manifest.json` खोलें और एडिटर का फ़ोल्डर चुनें।
2. अगर फ़ोल्डर में कॉपी की हुई प्रोजेक्ट फ़ाइल है, तो उसे सीधे `editor.exe` में खोलें।
3. अगर फ़ोल्डर `external-project-reference` है, तो उस फ़ोल्डर की `README.md` में दिया गया बाहरी GOG पथ इस्तेमाल करें।
4. अगर फ़ोल्डर `runtime-reference` है, तो कोई composer प्रोजेक्ट फ़ाइल नहीं मिली थी; एडिटर स्टार्टअप, इम्पोर्ट पथ और रेंडरिंग व्यवहार जाँचते समय दिए गए रनटाइम XML को सबसे नज़दीकी उपलब्ध डेटा संदर्भ मानें।

## कॉपी नीति

केवल वही फ़ाइलें यहाँ कॉपी की गई हैं जो रिपॉज़िटरी में पहले से हैं। GOG की व्यावसायिक स्थापना की फ़ाइलें सिर्फ़ पथ से संदर्भित हैं, उनकी प्रतिलिपि नहीं बनाई गई।
