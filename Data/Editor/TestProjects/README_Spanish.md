# Proyectos de prueba de los editores de Blitzkrieg

Esta carpeta ofrece una carpeta de prueba rápida por cada editor de recursos.

## Cómo se usa

1. Abre `manifest.json` y elige la carpeta del editor.
2. Si la carpeta contiene un archivo de proyecto copiado, ábrelo directamente en `editor.exe`.
3. Si la carpeta es `external-project-reference`, usa la ruta externa de GOG indicada en el `README.md` de esa carpeta.
4. Si la carpeta es `runtime-reference`, no se encontró ningún archivo de proyecto composer; usa el XML de ejecución indicado como la referencia de datos más cercana mientras pruebas el arranque del editor, las rutas de importación y el comportamiento de renderizado.

## Política de copia

Aquí solo se copian archivos que ya están en este repositorio. Los archivos de la instalación comercial de GOG se referencian solo por su ruta y no se duplican.
