Этот репозиторий — личный пет-проект Johannes Maria Frank. Я использую его для удовольствия и обучения, особенно чтобы практиковать агентное кодирование в brownfield-приложениях. Оригинальный README сохранен как `readme_original`.

Внимание: проект все еще находится в разработке.



# Что репозиторий может делать сегодня

- Содержит полный исходный код одиночной игры Blitzkrieg и игровые данные.

- Компилируется чисто из свежего решения `A7.sln` под современным MSVC.

- Включает нативную обработку исключений и современную поддержку отладки.

- Использует Git-субмодули для отсутствующих библиотек.

- Поддерживает отладку как нативного C++, так и WinDbg в VS Code Insiders.

- Удалена устаревшая система BugSlay и заменена стандартными C++ assert.



# История на сегодняшний день

- Найдены отсутствующие библиотеки и добавлены как субмодули.

- Создана виртуальная машина Windows XP SP3 с Visual Studio 6 для изучения старой среды.

- VS6 был нестабилен и часто падал, поэтому работа была перенесена на современные инструменты.

- Установлен Visual Studio 2010, а старый проект `.dwr` преобразован в `.sln`.

- Решение загружено в VS 2026 Insiders и обновлены все зависимости.

- Две недели агентного кодирования потребовались, чтобы заставить решение компилироваться из чистого состояния без ошибок и предупреждений.

- Это не означало, что игра полностью работает, но она один раз дошла до загрузки туториала, а видео и начальное меню уже запускались.

- Разработка перенесена в VS Code Insiders из-за лучших инструментов.

- Настроены два варианта отладки: нативный C++ и WinDbg.

- BugSlay удален, потому что он усложнял отладку, и в одном случае падал после падения.

- BugSlay заменен на простые стандартные C++ assert.

- С удалением BugSlay проект готов к продолжению отладки до полного запуска.
