# P08-M01.5 — Renderer-Neutral Game Asset Bridge

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans`; execute this packet before P08-M02.

**Objective:** Make the existing game-facing texture, font, and mesh manager calls produce renderer-neutral resources for SDL GPU without linking the legacy DirectX resource implementations.

**Reason:** P08-M02 now reaches deterministic SDL readback, but the capture contains only the small untextured subset because `TextureManagerGpu` and `FontManagerGpu` are stubs. The parity gate must not be weakened to conceal missing assets.

**Scope:** Add startup-safe singleton access, load the existing DDS/mipmap representation through `IDataStorage`/`IDataStream`, upload it through `TextureGpu`, cache resources with explicit ownership, bind textures for both indexed and non-indexed draws, and preserve the existing renderer-neutral mesh adapter. Implement the minimum font/text resource path needed by the reference scene. Do not link `Texture.cpp`, `Font.cpp`, `GeometryMesh.cpp`, or DirectX headers into `GFXGPU.dll`.

**Exit criteria:** SDL reference capture still exits cleanly; texture resources are non-null and uploaded; mesh resources load through the renderer-neutral adapter; the standalone smoke suite passes; and P08-M02 can be rerun against the unchanged parity thresholds. Font metrics remain a separate follow-up only if the reference scene proves to depend on them after the scene/render-state audit.

**Allowed files:** `Sources/src/GFXGPU/GlobalsLoader.cpp`, `Sources/src/GFXGPU/GfxGpuObjectFactory.cpp`, `Sources/src/GFXGPU/TextureGpu.h`, `Sources/src/GFXGPU/TextureGpu.cpp`, `Sources/src/GFXGPU/GraphicsEngineGpu.cpp`, `Sources/src/GFXGPU/MeshGpu.cpp`, `Sources/src/GFXGPU/MeshManagerGpu.cpp`, `build.zig`, and focused evidence/tests.
