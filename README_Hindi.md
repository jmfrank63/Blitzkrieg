यह रिपॉज़िटरी Johannes Maria Frank का व्यक्तिगत पेट प्रोजेक्ट है। मैं इसे आनंद और सीखने के लिए उपयोग करता हूँ, विशेष रूप से ब्राउनफ़ील्ड अनुप्रयोगों में एजेंटिक कोडिंग का अभ्यास करने के लिए। मूल README `readme_original` में सुरक्षित है।

चेतावनी: यह परियोजना अभी भी प्रगति पर है।



# यह रिपॉज़िटरी आज क्या कर सकती है

- Blitzkrieg सिंगल-प्लेयर के संपूर्ण स्रोत कोड और गेम डेटा को समेटे हुए है।

- आधुनिक MSVC टूलिंग के तहत एक ताज़ा `A7.sln` सॉल्यूशन से क्लीनली बनती है।

- नेटिव एक्सेप्शन रिपोर्टिंग और आधुनिक डिबगिंग सपोर्ट शामिल है।

- गायब लाइब्रेरीज़ को Git सबमॉड्यूल के रूप में जोड़ा गया है।

- VS Code Insiders में मूल C++ और WinDbg दोनों डिबगर समर्थित हैं।

- पुरानी BugSlay क्रैश हैंडलिंग को हटाकर मानक C++ assert से बदला गया है।



# अब तक का इतिहास

- गायब लाइब्रेरीज़ मिलीं और उन्हें Git सबमॉड्यूल के रूप में जोड़ा गया।

- पुराने वातावरण की जांच के लिए Windows XP SP3 VM में Visual Studio 6 इंस्टॉल किया गया।

- VS6 अस्थिर था और बार-बार क्रैश होता था, इसलिए आधुनिक टूल्स पर शिफ्ट किया गया।

- Visual Studio 2010 इंस्टॉल किया और पुराने `.dwr` प्रोजेक्ट को `.sln` में बदला गया।

- सॉल्यूशन को VS 2026 Insiders में लोड किया और सभी डिपेंडेंसीज़ अपडेट कीं।

- दो हफ्तों की एजेंट-केंद्रित कोडिंग के बाद सॉल्यूशन को क्लीन स्थिति से बिना त्रुटियों या चेतावनियों के कंपाइल करने में सक्षम बनाया गया।

- इसका मतलब यह नहीं था कि गेम पूरी तरह से चल रहा था, लेकिन यह एक बार ट्यूटोरियल लोड तक पहुंच गया, और वीडियो तथा प्रारंभिक मेन्यू पहले से लोड हो रहे थे।

- बेहतर टूल्स के लिए विकास को VS Code Insiders में ले जाया गया।

- दो डिबग विकल्प कॉन्फ़िगर किए गए: नेटिव C++ और WinDbg।

- BugSlay को हटाया गया क्योंकि यह डिबगिंग को कठिन बनाता था, और एक मामले में यह क्रैश के बाद भी क्रैश हो गया।

- BugSlay को सरल मानक C++ assert से बदला गया।

- BugSlay हटने के साथ, परियोजना अब पूर्ण रन की दिशा में फोकस्ड रनटाइम डिबगिंग के लिए तैयार है।

4. C++ प्रोजेक्ट्स को एक-एक करके Zig कोड से बदलना शुरू करें।
