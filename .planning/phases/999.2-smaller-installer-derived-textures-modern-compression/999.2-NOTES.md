# 999.2 Smaller installer — notes

Captured 2026-09-29 during the plan-6 hand try. Johannes wants the installer package to be as small as possible, and later a modern compressor in place of zip/.pak (xz or bz2 were mentioned).

**Decision (Johannes, 2026-09-29): only the download size matters.** Installed size does not ("a few GB on disk is nothing"). The package is compressed as hard as possible, fully unpacked at install, and read as loose files. So anything derivable can be left out of the download and recreated at install time; nothing needs to be squeezed on disk.

## Measured: Data is 2817 MB
| Part | Size | Files |
|---|---|---|
| `*_h.dds` (32-bit ARGB, top quality) | 1127 MB | 6065 |
| `*_l.dds` (16-bit 565/4444/1555, same pixel size) | 597 MB | 6065 |
| `*_c.dds` (DXT1/DXT5, same pixel size) | 314 MB | 6065 |
| non-DDS (models, sounds, maps, xml, …) | 779 MB | |
| season variants `w`/`a` (inside the rows above) | ≈ 543 MB Nival + 67 MB generated | |

## Ideas, in order of value
1. **Drop `_c` and `_l` from packages (−911 MB).** They are the same image as `_h` in formats for 2003 video memory. `GFXGPU/GfxGpuObjectFactory.cpp` `ResolveStreamName` tries the configured quality suffix, then `_h`, `_c`, `_l`. If a lower quality setting is still wanted, convert `_h` at load time; the DXT and 16-bit codecs already exist in `tools/zig/season_textures.zig`. Check every other reader of `_c`/`_l` first (the old DX8 GFX module, the resource and map editors, the icon readers, `TextureManager.cpp` quality handling). Decide whether the repository keeps them; git history keeps them regardless.
2. **Generate the missing season textures at build/stage time** instead of committing them. `zig build season-textures -- <Data>` takes about 2 s, is byte-deterministic, and never overwrites existing files. With (1), only `_h` needs generating. Keep the runtime fallback (`Scene/VisObjBuilder.cpp` `GetSeasonedMeshTexture`) for mods. Update `TestMissingSeasonTextureFallsBack`: once the files are generated, no unit lacks `1w`, so the test needs a fixture unit or a hidden file.
3. **Do not generate Nival's own season textures:** they are hand-painted (e.g. the Flak38 winter paint keeps traces of the summer camouflage), so generating them would lose original art (≈ 543 MB).
4. **Compression (download only):**
   - Compress the whole package as hard as possible: xz -9e or zstd --ultra -22 --long, whichever is smaller for this data (measure both; DDS, .mod and .xml compress well). Decompression speed at install matters little.
   - At install time, unpack fully to loose files and run the derivation step (1–2); the game reads loose files, with no .pak at runtime needed for shipped data (check that StreamIO's loose-file storage serves Data as fast as the .pak path, and keep `.pak` reading for mods and GeneratedData).
   - Alternative for (1): let the renderer use `_h` always and never recreate `_c`/`_l`. Simpler if nothing else needs them; check all readers first.
   - Measure: download size before and after each step, and install time.
