<objective>
Replace M1's refusal to delete a referenced object with the MFC editor's cascade (D-04), in one compound undo step, and fix `NMapOverlay::FindReferences` (script-ID groups, entrenchments, reserve positions, mobileScriptIDs, link ID 0).

Amendment C3 (recorded in 04-01's decision-log entry): a reserve position is erased when either its artillery or its truck is deleted (MFC `RemoveObjectFromReservePositions`), and a start command whose target is the deleted object gets target link ID 0 (RMGC_INVALID) rather than a dangling link.

Purpose: map makers can delete units that start commands and reserve positions name, as in the MFC editor, without breaking the game's loaders.
Output: cascade in MapOverlay, tombstones in the session, summary in the status bar, fake bridge modelling references, tests on the core, map-file and engine tiers.
</objective>
