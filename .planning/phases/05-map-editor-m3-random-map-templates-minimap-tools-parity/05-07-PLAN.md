## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user map images (.tga/.dds) -> engine decoder -> texture | pre-built minimap images are files on disk; decoding must not crash on malformed images |
| image writing next to the map | the command writes into the user's map folder — never into Data |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-07-01 | Tampering | image decode of user files | medium | mitigate | decode only through the engine's image processor behind Guarded; a malformed image refuses the Game mode with a status note, never a crash |
| T-05-07-02 | Tampering | writing into shipped Data | high | mitigate | the command requires a saved user map (Save As for shipped/never-saved); the bridge takes the map's own path and refuses paths under the shipped root (the isShipped rule) |
| T-05-07-03 | Tampering | minimap edits dirtying the map | low | mitigate | minimap reads and image creation never touch the snapshot; engine test asserts not-dirty after each |
</threat_model>
