- `UnsavedPrompt { pending: ?Pending, phase: idle | asking | saving }` with `guard(dirty, action) -> .proceed(action) | .asked`, `answer(.save | .dont_save | .cancel, needs_save_as: bool) -> .save | .save_as | .proceed(action) | .dropped`, `saveFinished(ok) -> ?Pending` (continue on success, drop on failure or a cancelled Save As).
- `FileActions` owns a `prompt: UnsavedPrompt`; `next(dirty, needs_save_as)` routes open_requested and quit_requested through `guard`, returns `.ask_unsaved` while asking, turns a dialog's `.cancelled` into `.dialog_cancelled`, and after a save made for the prompt returns the pending step.
- Tests: clean -> Open and Quit go straight through; dirty -> both ask; Cancel drops; Don't save proceeds; Save with a path saves then proceeds; Save with needs_save_as shows Save As and proceeds only after the save's path arrived and saved; a cancelled Save As drops the pending action; a failed save drops it and keeps the map dirty.
panels.zig: draw an ImGui modal popup "Unsaved changes" ("<name> has changes that are not saved.") with buttons [Save] [Don't save] [Cancel] while the prompt asks; buttons call `answer`; `act` executes save / save_as / the pending step and reports a failed save on the status line (the prompt drops the pending action, so a quit after a failed save does not quit).
main.zig `run`: SDL_EVENT_QUIT and SDL_EVENT_WINDOW_CLOSE_REQUESTED set `state.actions.quit_requested = true` instead of ending the loop; the loop ends when `act` returns true.
smoke.zig: new Input `.window_close` (pushes SDL_EVENT_WINDOW_CLOSE_REQUESTED for the window) and `.answer: UnsavedChoice` (calls the prompt's answer as the modal's button would); after "the saved map opens again" add steps: a brush stroke makes the map dirty (expect `painted`); closing the window asks (new Expect `unsaved_prompt_open`: prompt asking, loop still running); Cancel keeps it (new Expect `prompt_cancelled`: dirty, same path, not quitting); Ctrl+Z undoes the stroke (expect clean).
